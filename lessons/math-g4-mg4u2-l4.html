أسئلة تدريبية بالإجابات

1. في المستعمرة 5,328 نملة، منها 2,164 إناث والباقي ذكور. أي معادلة تمثل عدد الذكور a؟

  1. ⁦a − 2,164 = 5,328⁩
  2. ⁦2,164 − a = 5,328⁩
  3. ⁦5,328 + a = 2,164⁩
  4. ⁦2,164 + a = 5,328⁩
الإجابة: ⁦2,164 + a = 5,328⁩

2. أي عملية نستخدمها لإيجاد n في ⁦14,000 − n = 6,000⁩؟

  1. ⁦14,000 + 6,000⁩
  2. ⁦14,000 × 6,000⁩
  3. ⁦6,000 − 14,000⁩
  4. ⁦14,000 − 6,000⁩
الإجابة: ⁦14,000 − 6,000⁩

3. هناك 12,000 نوع من النمل، 2,500 منها في أفريقيا والباقي x. أي معادلة تمثل المسألة؟

  1. ⁦x − 2,500 = 12,000⁩
  2. ⁦x + 12,000 = 2,500⁩
  3. ⁦12,000 + x = 2,500⁩
  4. ⁦2,500 + x = 12,000⁩
الإجابة: ⁦2,500 + x = 12,000⁩
