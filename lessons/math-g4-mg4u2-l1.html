أسئلة على درس خواص عملية الجمع رياضيات الصف الرابع الابتدائي – ترم أول

هذه الصفحة للطالب وولي الأمر: أسئلة تدريبية بإجاباتها على درس خواص عملية الجمع من الوحدة «إستراتيجيات عمليتي الجمع والطرح» في رياضيات الصف الرابع الابتدائي، للمنهج المصري. جرّب أن تجيب أولًا ثم اقرأ الإجابة.

أسئلة تدريبية بالإجابات

1. أي مساواة تمثل خاصية العنصر المحايد الجمعي؟

  1. ⁦(8 + 2) + 1 = 8 + (2 + 1)⁩
  2. ⁦8 − 0 = 8⁩
  3. ⁦8 + 2 = 2 + 8⁩
  4. ⁦8 + 0 = 8⁩
الإجابة: ⁦8 + 0 = 8⁩

2. أي مساواة تمثل خاصية الإبدال؟

  1. ⁦6 + 0 = 6⁩
  2. ⁦6 − 2 = 2 − 6⁩
  3. ⁦(6 + 2) + 1 = 6 + (2 + 1)⁩
  4. ⁦6 + 2 = 2 + 6⁩
الإجابة: ⁦6 + 2 = 2 + 6⁩

3. ما الذي لاحظته في هذه المسائل الثلاث؟

  1. الأقواس تغيّر المجموع دائمًا
  2. المجموع الأكبر هو ما بين الأقواس
  3. لا يمكن حل المسائل التي فيها أقواس
  4. تغيير تجميع الأعداد بالأقواس لا يغيّر المجموع
الإجابة: تغيير تجميع الأعداد بالأقواس لا يغيّر المجموع

4. هل تنطبق خاصية الدمج على الطرح؟

  1. نعم، لأن الأقواس لا تغيّر الناتج
  2. لا يمكن الحكم
  3. نعم، في كل الأحوال
  4. لا، لأن تغيير الأقواس يغيّر الناتج
الإجابة: لا، لأن تغيير الأقواس يغيّر الناتج
